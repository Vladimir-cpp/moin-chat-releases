# Moin

Небольшой мессенджер для своих: текстовый чат и голосовой звонок один на один.
Здесь лежат готовые сборки для Android.

## Установка

1. Скачайте последний `moin-*.apk` на странице [Releases](../../releases/latest) и откройте его. Android спросит, можно ли устанавливать приложения из этого источника (браузера или «Файлов») — разрешите.
2. Если на телефоне уже стоит более ранняя тестовая сборка Moin, сначала удалите её: новая подписана другим ключом и поверх не встанет.

Если Play Protect предупредит о приложении не из магазина, выберите «Всё равно установить».

## Первый запуск

Вам пришлют картинку с QR-приглашением. Откройте Moin, нажмите «QR из картинки» и выберите её (или наведите камеру на QR). Moin проверит подключение — и можно писать и звонить.

## Обновления

Moin сам проверяет, вышла ли новая версия, не чаще раза в сутки. Проверить вручную: Настройки → «Проверить обновления». Когда версия найдётся, кнопка сменится на «Обновить до …»: приложение скачает сборку и предложит её установить. История и настройки сохраняются.
